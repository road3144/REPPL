# 실시간 진행률 반영(SSE)

Method: get
Tag : deprecated
URI: api/v1/jobs/{jobId}/events
상태: 개발 전
우선순위: 중

### **Request Header**

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Accept | `String` | 필수 | `text/event-stream` |
| Cookie | `String` | 필수 | 세션 쿠키 |
| Last-Event-ID | `String` | 선택 | 재연결 지원 시 |

### **요청 예시**

```
GET api/v1/jobs/job_2f8a1c/events
Accept: text/event-stream
```

### **응답 예시**

```
event: snapshot
data: {"status":"PROCESSING","progress":10,"stage":"GPU_ASSIGNED","message":"GPU allocated"}

event: progress
data: {"progress":55,"stage":"GPU_RUNNING","message":"Compositing"}

event: done
data: {"status":"SUCCEEDED"}
```
