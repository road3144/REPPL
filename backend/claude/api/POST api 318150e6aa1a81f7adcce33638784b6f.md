# POST api

Topic: /api/v1/url
상태: 개발 전
우선순위: 중

### **Request Header**

| **파라미터** | **타입** | **필수여부** | **설명** |
| --- | --- | --- | --- |
| Content-Type | `String` | 필수 | `application/json` |
| Authorization | `String` | 필수 | `{jwtToken}` |

### **Request Body**

| **파라미터** | **타입** | **필수여부** | **설명** |
| --- | --- | --- | --- |
| nickname | `String` | 필수 | 최소 4자 이상, 10자 이하 (소문자, 숫자 |
| name | `String` | 필수 | 변호사 실명 |
| email | `String` | 필수 | 변호사 이메일 |
| introduction | `String` | 필수 | 변호사 소개 |
| certificationInfo | `String` | 필수 | 변호사 자격 정보 |
| career | `String` | 필수 | 경력사항 |

### **요청 예시**

```json
POST /api/v1/lawyers
Content-Type: application/json

{
  "nickname": "천원짜리 변호사",
  "name": "천원만",
  "email": "1000won@gmail.com",
  "introduction": "안녕하세요 천원짜리 변호사 입니다. 확실한 공증 보장합니다",
  "certificationInfo": "자격번호 : 1232191233",
  "career": "2010 - 2020 : 김앤장 \n 2020 - 개인 로펌"
}

```

### **Response Elements**

| **필드** | **타입** | **설명** |
| --- | --- | --- |
| lawyerId | `Long` | userId와 동일 |
| nickname | `String` | 최소 4자 이상, 10자 이하 (소문자, 숫자 |
| name | `String` | 변호사 실명 |
| email | `String` | 변호사 이메일 |
| introduction | `String` | 변호사 소개 |
| certificationInfo | `String` | 변호사 자격 정보 |
| career | `String` | 경력사항 |
| isAccepted | `BOOLEAN` | 승인 여부 |
| isPublic | `BOOLEAN` | 계정 활성화 상태 |
