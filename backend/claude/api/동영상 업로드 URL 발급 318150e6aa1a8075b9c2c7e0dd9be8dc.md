# 동영상 업로드 URL 발급

Method: post
Tag : api
URI: /api/v1/url/video 
담당자: 신윤수
상태: 개발 전
우선순위: 상

### **Request Header**

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Content-Type | `String` | 필수 | `application/json` |
| Cookie | `String` | 필수 | 세션 쿠키 |

### **Query Param**

없음

### **Request Body Elements**

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| video.filename | `String` | 필수 | 영상 파일명 |
| video.contentType | `String` | 필수 | 예: `video/mp4` |
| video.sizeBytes | `Long` | 필수 | 바이트 크기 |

### **요청 예시**

```
POST /api/v1/url/video
Content-Type: application/json
```

```json
{
  "video": {
    "filename":"input.mp4",
    "contentType":"video/mp4",
    "sizeBytes":73400210
  }
}
```

---

### **Response Elements**

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| upload.video.key | `String` | S3 저장 key (`tmp/{sessionId}/video/{uuid}_{filename}`) |
| upload.video.url | `String` | **presigned PUT URL** |
| upload.video.method | `String` | `PUT` |
| upload.video.headers | `Object` | 업로드 헤더(예: `Content-Type`) |
| upload.video.expiresAt | `String` | presigned 만료 시각(ISO-8601) |

---

### **응답 예시 (200)**

```json
{
  "success":true,
  "data": {
    "upload": {
      "video": {
        "key":"tmp/sess_abc/video/2aa_input.mp4",
        "url":"https://s3...presigned-put...",
        "method":"PUT",
        "headers": { "Content-Type":"video/mp4" },
        "expiresAt":"2026-03-04T03:30:00Z"
      }
```

### **실패 예시 (400) — 파일 크기 초과**

```json
{
  "success":false,
  "data":null,
  "error": {
    "code":"FILE_TOO_LARGE",
    "message":"파일 크기가 제한을 초과했습니다.",

```
