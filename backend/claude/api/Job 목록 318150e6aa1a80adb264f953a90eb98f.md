# Job 목록

Method: get
Tag : api
URI: /api/v1/jobs
담당자: 태환 길
상태: 개발 전
우선순위: 중

### **Request Header**

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Cookie | `String` | 필수 | 세션 쿠키 |

### **Query Param**

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| page | `Integer` | 선택 | 기본 0 |
| size | `Integer` | 선택 | 기본 10 |
| sort | `String` | 선택 | 기본 `createdAt` |
| direction | `String` | 선택 | 기본 `desc` |

### **요청 예시**

```
GET api/v1/jobs?page=0&size=10&sort=createdAt&direction=desc
```
