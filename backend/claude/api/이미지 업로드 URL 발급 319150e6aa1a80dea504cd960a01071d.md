# 이미지 업로드 URL 발급

Method: post
Tag : api
URI: /api/v1/url/images
담당자: 신윤수
상태: 개발 전
우선순위: 상

### **Request Header**

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Content-Type | `String` | 필수 | `application/json` |
| Cookie | `String` | 필수 | 세션 쿠키 |

### **Query Param**

없음

### **Request Body Elements**

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| refImages | `List<Object>` | 필수 | 다각도 이미지 리스트 |
| refImages[].filename | `String` | 필수 | 이미지 파일명 |
| refImages[].contentType | `String` | 필수 | 예: `image/jpeg` |
| refImages[].sizeBytes | `Long` | 필수 | 바이트 크기 |

### **요청 예시**

```
POST /api/v1/url/images
Content-Type: application/json
```

```json
{
  "refImages": [
    { "filename":"front.jpg", "contentType":"image/jpeg", "sizeBytes":345678 },
    { "filename":"side.jpg",  "contentType":"image/jpeg", "sizeBytes":456789 }
  ]
}
```

---

### **Response Elements**

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| upload.refImages | `List<Object>` | 이미지 업로드 정보 목록 |
| upload.refImages[].key | `String` | S3 저장 key (`tmp/{sessionId}/images/{uuid}_{filename}`) |
| upload.refImages[].url | `String` | **presigned PUT URL** |
| upload.refImages[].method | `String` | `PUT` |
| upload.refImages[].headers | `Object` | 업로드 시 포함해야 할 헤더(예: `Content-Type`) |
| upload.refImages[].expiresAt | `String` | presigned 만료 시각(ISO-8601) |

> 포인트: **서버는 URL이 아니라 “key”를 진짜로 저장해야 함.** (URL은 만료됨)
> 
> 
> 저장 위치는 RDB가 아니라 **세션(혹은 세션 스토어/Redis)** 임시 저장이면 충분.
>
