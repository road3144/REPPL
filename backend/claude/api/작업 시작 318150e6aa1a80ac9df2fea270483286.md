# 작업 시작

Method: post
Tag : api
URI: /api/v1/jobs
담당자: 태환 길
상태: 개발 전
우선순위: 상

### **Request Header**

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Content-Type | `String` | 필수 | `application/json` |
| Cookie | `String` | 필수 | 세션 쿠키 |

### **Query Param**

없음

### **Request Body Elements**

| 필드 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| videoKey | `String` | 필수 | 최종 사용할 영상 S3 key |
| refImageKeys | `List<String>` | 필수 | 최종 사용할 이미지 S3 key 목록 |
| options | `Object` | 선택 | 작업 옵션 |
