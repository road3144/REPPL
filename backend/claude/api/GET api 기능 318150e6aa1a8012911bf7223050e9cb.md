# GET api 기능

Method: get
Tag : presigned
URI: /api/v1/me 
상태: 확인함
우선순위: 중

### **Request Header**

| **파라미터** | **타입** | **필수여부** | **설명** |
| --- | --- | --- | --- |
| Content-Type | `String` | 필수 | `application/json` |
| Authorization | `String` | 필수 | `{jwtToken}` |

### **Query Param**

| **파라미터** | **타입** | **필수여부** | **설명** |
| --- | --- | --- | --- |
| `page` | `Integer` | 선택 | 페이지 번호 (기본값: 0). |
| `size` | `Integer` | 선택 | 한 페이지에 보여줄 사용자 수 (기본값: 10). |
| `sort` | `String` | 선택 | 정렬 기준 필드 (`created_at`, `username`, 등). 기본값: `created_at` |
| `direction` | `String` | 선택 | 정렬 방향 (`asc`, `desc`). 기본값: `asc`. |
| `searchQuery` | `String` | 선택 | 검색어 |

### **요청 예시**

```json
GET /api/v1/lawyers/{lawyerId}
Content-Type: application/json

```

### **Response Elements**

| **필드** | **타입** | **설명** |
| --- | --- | --- |
| lawyerId | `Long` | userId와 동일 |
| nickname | `String` | 최소 4자 이상, 10자 이하 (소문자, 숫자 |
| name | `String` | 변호사 실명 |
| email | `String` | 변호사 이메일 |
| introduction | `String` | 변호사 소개 |
| certificationInfo | `String` | 변호사 자격 정보 |
| career | `String` | 경력사항 |
| isAccepted | `BOOLEAN` | 승인 여부 |
| isPublic | `BOOLEAN` | 계정 활성화 상태 |
| reviewList | `List` | 변호사 리뷰 리스트 |
|  |  |  |
