# Job 상태 조회

Method: get
Tag : api
URI: /api/v1/jobs/{jobId}
담당자: 태환 길
상태: 개발 전
우선순위: 중

### **Request Header**

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Cookie | `String` | 선택 | 로그인/세션 기반이면 포함 |

### **Query Param**

없음

### **요청 예시**

```
GET /api/v1/jobs/{jobId}
```

---

### **Response Elements**

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| jobId | `String` | jobId |
| status | `String` | `QUEUED` / `RUNNING` / `DONE` / `FAILED` |
| progress | `Int` | 0~100 |
| message | `String` | 상태 메시지 |
| result.videoKey | `String` | 결과 영상 S3 key (DONE일 때) |

---

### **응답 예시 (200) — RUNNING**

```json
{
  "success":true,
  "data": {
    "jobId":"job_20260304_000123",
    "status":"RUNNING",
    "progress":42,
    "message":"Extracting frames",
    "result":null
  },
  "error":null
}
```

---

### **응답 예시 (200) — DONE**

```json
{
  "success":true,
  "data": {
    "jobId":"job_20260304_000123",
    "status":"DONE",
    "progress":100,
    "message":"Completed",
    "result": {
      "videoKey":"results/job_20260304_000123/output.mp4"
    }
  },
  "error":null
}
```
