# 진행률/상태 조회

Method: get
Tag : deprecated
URI: api/v1/jobs/{jobId}
상태: 개발 전
우선순위: 중

### **Request Header**

| 파라미터 | 타입 | 필수여부 | 설명 |
| --- | --- | --- | --- |
| Cookie | `String` | 필수 | 세션 쿠키 |

### **요청 예시**

```
GET api/v1/jobs/job_2f8a1c
```

### **Response Elements**

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| status | `String` | `INITED/UPLOAD_URLS_ISSUED/UPLOADED/QUEUED/PROCESSING/SUCCEEDED/FAILED` |
| progress | `Integer` | 0~100 |
| stage | `String` | UI용 단계 |
| message | `String` | 메시지 |
