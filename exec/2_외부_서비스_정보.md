# 외부 서비스 정보

## 1. Google Gemini API (AI 이미지 생성)

### 서비스 개요
- **용도**: 원본 영상 첫 프레임에 제품 이미지를 합성한 프리뷰 이미지 생성
- **사용 모델**: `gemini-3.1-flash-image-preview` (Nano Banana 2)
- **호출 방식**: REST API (google-genai Python SDK 사용)

### 가입 및 설정 방법

#### 방법 1: Google AI Studio (Developer API Key) — 무료, 일일 한도 있음

1. [Google AI Studio](https://aistudio.google.com/) 접속
2. Google 계정으로 로그인
3. 좌측 메뉴 > **Get API Key** 클릭
4. **Create API Key** 버튼으로 키 발급
5. 발급받은 키를 `ai/.env` 파일에 설정:
   ```
   GEMINI_API_KEY=<발급받은 API Key>
   ```

> ⚠️ 무료 플랜은 일일 요청 수 제한이 있습니다. 일일 한도 소진 시 다음 날까지 대기하거나 다른 키를 사용해야 합니다.

#### 방법 2: Google Cloud Vertex AI — 유료 (크레딧 차감), 일일 한도 없음 (권장)

1. [Google Cloud Console](https://console.cloud.google.com/) 접속
2. 새 프로젝트 생성 또는 기존 프로젝트 선택
3. **APIs & Services** > **Enable APIs** > `Vertex AI API` 활성화
4. 서비스 계정 또는 `gcloud auth application-default login` 으로 인증
5. `ai/.env` 파일에 설정:
   ```
   GOOGLE_CLOUD_PROJECT=<GCP 프로젝트 ID>
   GOOGLE_CLOUD_LOCATION=global
   ```
6. GPU 서버에서 `gcloud auth application-default login` 실행하여 인증

### 관련 파일
- `ai/main.py` — Gemini API 호출 로직 (프리뷰 이미지 생성, 합성 파이프라인)
- `ai/config.py` — API 키 환경변수 로드

## 2. SSAFY GMS (Generative Model Service) API

### 서비스 개요
- **용도**: 사용자 프롬프트 검증 (영상 PPL 배치 요청으로 유효한지 판단)
- **사용 모델**: `gemini-2.5-flash` (GMS를 통한 프록시 호출)
- **API 엔드포인트**: `https://gms.ssafy.io/gmsapi/generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent`

### 설정 방법

1. SSAFY 교육 포털에서 GMS API Key 발급
2. `ai/.env` 파일에 설정:
   ```
   GMS_API_KEY=<GMS API Key>
   ```

### 기능 상세
- 사용자가 입력한 한국어 프롬프트가 "영상 속 제품 배치 요청"으로 유효한지 검증
- 유효한 프롬프트에서 Grounding DINO 객체 검출용 영어 키워드 자동 추출
- 예: "책상 위 빈 공간에 콜라를 놓아줘" → `{"valid": true, "dino_keyword": "coca cola can"}`

### 관련 파일
- `ai/prompt_validator.py` — GMS API 호출 및 프롬프트 검증 로직

## 3. AWS S3 (Amazon Simple Storage Service)

### 서비스 개요
- **용도**: 영상 파일, 제품 이미지, 프리뷰 이미지, 합성 결과 영상 저장
- **리전**: `ap-northeast-2` (서울)
- **접근 방식**: 
  - Backend: Spring Cloud AWS S3 (Presigned URL 발급)
  - Frontend: 브라우저에서 Presigned URL로 S3 직접 업로드/다운로드
  - AI Worker: boto3 SDK로 직접 업/다운로드

### 가입 및 설정 방법

1. [AWS Console](https://aws.amazon.com/) 접속 및 계정 생성
2. S3 버킷 생성:
   - 리전: `ap-northeast-2` (서울)
   - 버킷 이름 설정
   - CORS 정책 설정 (프론트엔드 직접 업로드 허용)
3. IAM 사용자 생성:
   - S3 접근 권한 부여 (`AmazonS3FullAccess` 또는 커스텀 정책)
   - Access Key / Secret Key 발급
4. 환경변수에 설정:
   ```
   AWS_ACCESS_KEY=<Access Key>
   AWS_SECRET_KEY=<Secret Key>
   AWS_REGION=ap-northeast-2
   AWS_S3_BUCKET=<버킷명>
   ```

### S3 버킷 CORS 설정 예시

```json
[
  {
    "AllowedHeaders": ["*"],
    "AllowedMethods": ["GET", "PUT", "POST"],
    "AllowedOrigins": ["https://j14a401.p.ssafy.io"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

### 관련 파일
- `backend/src/main/resources/application.yml` — Spring Cloud AWS S3 설정
- `ai/s3_client.py` — boto3 기반 S3 업/다운로드 클라이언트
- `frontend/src/services/s3.ts` — Presigned URL 발급 및 브라우저 직접 업로드

## 4. Docker Hub

### 서비스 개요
- **용도**: Backend/Frontend Docker 이미지 레지스트리
- **이미지 이름**:
  - `<DOCKER_HUB_USER>/reppl-backend`
  - `<DOCKER_HUB_USER>/reppl-frontend`

### 가입 및 설정 방법

1. [Docker Hub](https://hub.docker.com/) 회원가입
2. GitLab CI/CD 변수에 설정:
   - `DOCKER_HUB_USER`: Docker Hub 사용자명
   - `DOCKER_HUB_PASSWORD`: Docker Hub 패스워드 또는 Access Token

### 관련 파일
- `.gitlab-ci.yml` — CI/CD 파이프라인에서 이미지 빌드/푸시

## 5. Let's Encrypt (SSL 인증서)

### 서비스 개요
- **용도**: HTTPS SSL/TLS 인증서 무료 발급 및 자동 갱신
- **도구**: Certbot
- **도메인**: `j14a401.p.ssafy.io`

### 설정 방법

1. EC2 서버에서 최초 인증서 발급:
   ```bash
   docker run --rm \
     -v certbot_www:/var/www/certbot \
     -v certbot_conf:/etc/letsencrypt \
     certbot/certbot certonly \
     --webroot -w /var/www/certbot \
     -d j14a401.p.ssafy.io \
     --agree-tos --email <이메일>
   ```
2. `docker-compose.yml`의 certbot 서비스가 12시간마다 자동 갱신

### 관련 파일
- `docker-compose.yml` — certbot 서비스 정의
- `nginx/nginx.conf` — SSL 인증서 경로 설정

## 7. Grounding DINO + SAM (AI 모델)

### 서비스 개요
- **용도**: 영상 속 객체 검출(DINO) 및 정밀 세그멘테이션(SAM)
- **외부 가입 불필요** (오픈소스 모델, 로컬 실행)

### 모델 파일

| 모델 | 파일명 | 다운로드 URL | 크기 |
|------|--------|-------------|------|
| Grounding DINO (SwinT) | `groundingdino_swint_ogc.pth` | [GitHub Release](https://github.com/IDEA-Research/GroundingDINO/releases/download/v0.1.0-alpha/groundingdino_swint_ogc.pth) | ~694MB |
| SAM ViT-H | `sam_vit_h_4b8939.pth` | [Meta AI](https://dl.fbaipublicfiles.com/segment_anything/sam_vit_h_4b8939.pth) | ~2.4GB |

### 관련 라이브러리
- `groundingdino-py==0.4.0` — Grounding DINO Python 래퍼
- `segment-anything==1.0` — SAM (Segment Anything Model)
- `torch==2.5.1+cu121` — PyTorch (CUDA 12.1)
- `torchvision==0.20.1+cu121` — TorchVision
