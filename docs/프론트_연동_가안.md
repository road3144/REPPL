# 프론트 연동 가안 (2026-03-11)

## 목적
- 백엔드 최종 명세 확정 전, 프론트 연동을 선행하기 위한 임시 기준입니다.
- 본 문서는 Jira/업무표 기록 및 팀 공유용입니다.

## 현재 가정
1. 인증/로그인 없음 (비인증 상태로 API 호출)
2. 업로드 완료 등록 API 없음 (S3 업로드 후 바로 Job 생성)
3. 상태값은 `QUEUED`, `RUNNING`, `COMPLETED`, `FAILED` 사용
4. Job 생성 옵션은 `brand`만 사용

## 프론트 임시 플로우
1. `POST /api/v1/url/video` 로 영상 Presigned URL 발급
2. 영상 파일을 S3로 `PUT`
3. `POST /api/v1/url/images` 로 이미지 Presigned URL 발급
4. 이미지 파일을 S3로 `PUT`
5. `POST /api/v1/jobs` 로 Job 생성 (`videoKey`, `refImageKeys`, `options.brand`)
6. `GET /api/v1/jobs` + `GET /api/v1/jobs/{jobId}` 폴링으로 상태 표시
7. 완료 시 `GET /api/v1/jobs/{jobId}/result` 로 다운로드 URL 수신

## 화면 동작 범위 (가안)
- DemoStudio
  - 영상 1개 + 레퍼런스 이미지 N개 업로드
  - 작업 생성
  - 작업 목록 조회
  - 진행 상태 표시(주기 폴링)
  - 완료 결과 다운로드

## 추후 확정 필요 항목
1. 상태 enum 최종값 (`SUCCEEDED` vs `COMPLETED` 등)
2. 업로드 완료 등록 API 필요 여부
3. Job 생성 옵션 최종 스키마 (길이/비율/탐지 방식)
4. 결과 메타데이터 응답 포함 여부

## 영향 범위
- 프론트 코드에만 반영, 백엔드 코드는 수정하지 않음
